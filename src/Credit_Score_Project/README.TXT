PROJECT TITLE: Credit Score Simulator
PURPOSE OF PROJECT: To mock the process of generating a credit score with user and password login.
VERSION or DATE: 6/8/26 (Started 4/6/2026)
AUTHORS: Ivan Thankachen
USER INSTRUCTIONS:

1. For Client:
a. All Process start by running the main function in User.java.
b. Choose between client and admin. Choose client.
c. Create new user if first time running program. Otherwise, log back in. 
d. Answer questions regarding credit.
e. Score is displayed and program is exited.

2. For Admin:
a. All Process start by running the main function in User.java.
b. Choose between client and admin. Choose admin.
c. Cycle through options. I would strongly recommend creating a couple of clients prior to option cycling. 
d. Select option 3 and logout when finished.
